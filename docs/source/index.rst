NuOscProbExact
==============

**NuOscProbExact** computes exact two-flavor and three-flavor neutrino
oscillation probabilities for arbitrary time-independent Hamiltonians,
using the SU(2) and SU(3) exponential expansions described in
`arXiv:1904.12391 <https://arxiv.org/abs/1904.12391>`_.

There is no approximation beyond floating-point round-off: the evolution
operator agrees with a direct matrix exponential to machine precision.

See the `README
<https://github.com/mbustama/NuOscProbExact/blob/master/README.md>`_ for
installation instructions and worked examples.
