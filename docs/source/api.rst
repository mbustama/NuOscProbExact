API reference
=============

The two core modules, :mod:`oscprob2nu` and :mod:`oscprob3nu`, are
self-contained: they need only ``numpy``, and they accept any Hermitian
Hamiltonian.  The remaining modules provide sample Hamiltonians and the
constants used to build them.
